5. WHAT THE ANALYSIS SCRIPTS DO WITH THESE ROWS
==============================================================================

Scripts 07 and 08 both call dropna(subset=['modelled_swe_mm']) when
they load the table, so blank rows are removed before any metric is
computed. Script 06 does not, because it reads only station_id and
date — it is measuring whether the STATION reported, which is a
question about the observations alone.

That difference is only a problem if blanks fall inside a study
period at a selected station. Section 3 above answers that.
